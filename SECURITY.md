# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in gophoner, please report it
privately rather than opening a public issue.

Use GitHub's private vulnerability reporting: go to the
[Security tab](https://github.com/M4elstr0m/gophoner/security) of this
repository and select **"Report a vulnerability"**. This opens a private
advisory visible only to you and the maintainer — no other contact
information is required.

Please include:
- A description of the vulnerability and its impact
- Steps to reproduce
- Any relevant logs or proof of concept

Reports will be acknowledged as soon as possible, with updates as the
issue is addressed.
